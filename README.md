# Calculator.py
A very simple-to-make Python calculator that supports Addition, Subtraction, Multiplcation, and Division!
# How to open
Make sure you have Python 3.0+ installed
Open VS code (or your prefered coding editor)
clone the repository: git clone https://github.com/At0tallynormalperson/Calculator.git
or download it manually: Code > Download .zip file > extract
double click the .py file and choose Visual Studio code if it prompts you
You're all set!
